# Секретная карта звёзд

Небольшой интерактивный квест на HTML, CSS и JavaScript. Работает без сервера и сторонних библиотек; Google Fonts используются только для оформления, если доступен интернет.

## Запуск в VS Code
1. Распакуйте ZIP в отдельную папку.
2. Откройте папку в VS Code.
3. Откройте `index.html` в браузере. Можно установить расширение Live Server и нажать **Go Live**.

## Публикация на GitHub Pages
1. Создайте репозиторий на GitHub.
2. Загрузите `index.html`, `style.css`, `script.js` и `README.md` в корень репозитория.
3. Откройте **Settings → Pages**.
4. В разделе Build and deployment выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем сохраните.
5. Подождите публикации и откройте ссылку, которую покажет GitHub Pages.

Текст финального сообщения можно изменить в `index.html`, внутри элемента `.reveal-message`.


## Атмосферный звук
В шапке страницы есть кнопка «ЗВУК: ВЫКЛ». Нажми её, чтобы включить тихий космический фон и редкие звуки-звёздочки. Звук генерируется браузером локально через Web Audio API, поэтому отдельный аудиофайл или музыкальная лицензия не нужны. На телефонах браузер разрешает звук только после нажатия пользователя. Нажми кнопку повторно, чтобы выключить звук.
